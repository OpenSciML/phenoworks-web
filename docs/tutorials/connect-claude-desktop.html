Tutorial: Connect PhenoWorks to Claude Desktop

Connect Claude Desktop on macOS to your PhenoWorks account so you can explore projects, discover analysis modules, search knowledge bases, and download results through conversation. This tutorial uses the hosted PhenoWorks API at https://api.phenoworks.org.

Claude runs the PhenoWorks MCP connector on your Mac and uses it to communicate with the API. Claude starts this process automatically; you do not need a separate MCP terminal.

Before you begin, install Claude Desktop and uv, and create an API key in your PhenoWorks account settings. The tools available to Claude depend on your account permissions and the modules installed in PhenoWorks.

1. Create a dedicated environment​

With uv installed, run these commands in Terminal:

mkdir -p ~/mcp-servers/phenoworks
cd ~/mcp-servers/phenoworks
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python phenoworks-mcp

The explicit Python path installs into this new environment even if another environment is already active. The SDK and MCP dependencies are installed automatically. You do not need to activate the environment.

Check that the executable starts and print its full path:

.venv/bin/phenoworks-mcp --help
printf '%s/.venv/bin/phenoworks-mcp\n' "$PWD"

Copy the printed path for the next step. Keep this folder in place: Claude will use its executable each time it connects.

2. Check the PhenoWorks API connection​

In Terminal, check that you can reach the hosted API:

curl --fail --show-error https://api.phenoworks.org/api/health

3. Add PhenoWorks to Claude Desktop​

Open Claude Desktop > Settings > Developer > Edit Config. On macOS, the configuration file is:

~/Library/Application Support/Claude/claude_desktop_config.json

Add the following configuration. If the file already contains MCP servers, add the phenoworks entry inside the existing mcpServers object and preserve the other entries.

{
  "mcpServers": {
    "phenoworks": {
      "command": "/Users/YOUR_USERNAME/mcp-servers/phenoworks/.venv/bin/phenoworks-mcp",
      "args": [
        "--transport",
        "stdio"
      ],
      "env": {
        "PHENOWORKS_API_BASE_URL": "https://api.phenoworks.org",
        "PHENOWORKS_API_KEY": "YOUR_API_KEY",
        "PHENOWORKS_AGENT_WORKSPACE_DIR": "/Users/YOUR_USERNAME/Downloads/phenoworks",
        "PHENOWORKS_PUBLIC_URL": "https://app.phenoworks.org/"
      }
    }
  }
}

Replace command with the full path printed in step 1, replace YOUR_USERNAME in the download path with your macOS username, and replace YOUR_API_KEY with your key. Use absolute paths in the JSON, not ~ or $HOME. Keep the configuration private and never include a real key in screenshots, chat messages, or committed files.

4. Restart Claude and start chatting​

Fully quit Claude Desktop with Cmd+Q, then reopen it and start a conversation. Ask:

Use PhenoWorks to check my connection, identify my account, and list my projects.

Allow the requested tool calls through Claude's approval controls. Once the connection works, try:

Show the datasets in the project I choose, and summarize their surveys and data products.

Find the available analysis modules and explain the inputs of one I choose.

List my PhenoWorks knowledge bases. Use the knowledge base I choose for every question in this conversation, search it before answering, and cite the source documents.

Check pipeline 123 and download its completed artifacts.

Replace example IDs with values from your account. Downloads are saved directly in the PHENOWORKS_AGENT_WORKSPACE_DIR folder on your Mac, for example artifact_4731_pipeline_results.xlsx. Claude launches the correct Python environment itself, so you can close Terminal after setup.

Troubleshooting​

ProblemWhat to check
Claude cannot start the connectorConfirm that command is the absolute executable path printed in step 1 and that the environment folder still exists. Run the executable with --help in Terminal.
The API cannot be reachedRepeat the health check in step 2 and check your network connection. Set the API base URL to https://api.phenoworks.org, without /api/health.
The API responds, but account requests failAsk Claude to call phenoworks_me to verify your API key. A successful health check does not verify credentials.
Downloads failUse an absolute, writable folder for PHENOWORKS_AGENT_WORKSPACE_DIR and replace YOUR_USERNAME with your macOS username.
Source citations open the wrong applicationCheck that PHENOWORKS_PUBLIC_URL points to https://app.phenoworks.org/.
Configuration changes have no effectFully quit Claude Desktop with Cmd+Q and reopen it.

For a self-hosted PhenoWorks instance, replace the API and application URLs with your instance's addresses. The PhenoWorks server must remain running and be reachable from your Mac.

5. Update the package later​

uv pip install \
  --python ~/mcp-servers/phenoworks/.venv/bin/python \
  --upgrade phenoworks-mcp

Fully restart Claude Desktop after updating. For clients with a similar mcpServers configuration, the same executable and stdio arguments can be used; consult the client's instructions for its configuration location.

Next steps​

Continue with Analyze Data with the Agent for examples of choosing inputs, reviewing a pipeline, and interpreting results. That tutorial describes the built-in PhenoWorks Agent interface; in Claude Desktop, use Claude's own tool approval controls and the local download folder configured above.
